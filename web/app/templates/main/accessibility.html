Accessibility statement

This is a study project that copies the patterns of a GOV.UK service. It is built with the GOV.UK Design System and aims to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA.

How it was tested

Every page and error state was checked with the axe-core automated tool, and the service was checked for use with a keyboard only.

Compliance status

This service is partially compliant with WCAG 2.2 AA. Automated checks find only part of the problems people meet, and it has not been tested by disabled people or audited by an accessibility specialist.
